# kavach-osint-recon
OSINT Reconnaissance Tool — Kavach Cyber Solutions
a Python OSINT reconnaissance tool that performs 
pre-engagement intelligence gathering on business domains — 
WHOIS analysis, subdomain enumeration via certificate 
transparency logs, breach exposure checks, technology 
fingerprinting, and historical exposure via Wayback Machine.

Used for real client security assessments at Kavach Cyber 
Solutions LLC to identify forgotten subdomains and exposed 
infrastructure before formal engagement.

Tech: Python, DNS-over-HTTPS, WHOIS, Certificate Transparency, 
Wayback Machine API
