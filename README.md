# kavach-osint-recon

OSINT Reconnaissance Tool — Kavach Cyber Solutions

A Python OSINT reconnaissance tool that performs pre-engagement
intelligence gathering on business domains:

- WHOIS analysis
- Subdomain enumeration via certificate transparency logs
- Breach exposure checks
- Technology fingerprinting
- Historical exposure via the Wayback Machine

Built to identify forgotten subdomains and exposed infrastructure
during security assessments.

## How to run

    pip install -r requirements.txt
    python3 osint_recon.py

## Tech

Python, DNS-over-HTTPS, WHOIS, Certificate Transparency, Wayback Machine API

Part of Kavach Cyber Solutions — a personal security tooling project
built in my own time. No client data is used or stored by this tool.
